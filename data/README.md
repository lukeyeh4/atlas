# Data

Sourced inputs for the Atlas model:

- `E = P · 8760 · u · PUE`
- `C = E · CI`
- `W = E · water rate`
- `A = E · fossil share · population`

Every value carries its source, year and a confidence level:

| Level | Meaning |
|---|---|
| measured | Official statistics or metered data |
| disclosed | A company's own report |
| estimated | Modelled by a third party, or derived by us with the arithmetic shown |
| projected | A forecast or design target |
| sample | Placeholder; none remain in these files |

All CSVs import directly into Google Sheets.

## How it's built

`sources/` holds research findings. Each is a JSON file with a source URL, year, confidence and note for every value, gathered from:
- Ember
- WRI Aqueduct
- World Bank
- China's environment ministry (MEE)
- OpenElectricity
- company sustainability reports
- AWS and Microsoft fact sheets

Five files in `sources/` are generated by scripts, not researched by hand: `country-grid.json`, `grid-us-states.json`, `country-wue.json`, `country-ws.json` and `country-pm25.json` (all keyed by ISO2), plus the GeoNames code table in `data/.cache/`. Hand research in `countries.json` and `water-disclosed.json` overrides them where a bulk source has a gap (Taiwan, Singapore) or an operator discloses water use.

`scripts/` turns those into the CSVs. Downloads are cached in `data/.cache/`, which git ignores.

```bash
python3 data/scripts/build_all.py                # everything but the population grid
python3 data/scripts/build_all.py --population   # also the population grid (~480 MB download)
```

The population grid needs `pip install numpy tifffile imagecodecs`; the cell tiles need `numpy`. Everything else is standard-library Python.

| Script | Downloads | Writes |
|---|---|---|
| `ember.py` | Ember yearly data (global + US states) | `sources/country-grid.json`, `sources/grid-us-states.json` |
| `country_wue.py` | World Bank CCKP ERA5 climate; Shumba et al. African WUE dataset | `sources/country-wue.json` |
| `population_grid.py` | GHSL 2025 population, 30″ | `population-grid-025.csv` |
| `cells.py` | — | `cells/` (from `population-grid-025.csv`) |

| `subnational_grid.py` | — | `subnational-grid.csv` |

To refresh a year, re-run: `ember.py` picks up new Ember releases. For values researched by hand, edit the JSON in `sources/`, then rebuild.

## Known limits

- **Carbon intensity basis differs by source:** Ember is lifecycle; MEE (China) and OpenElectricity (Australia) are direct combustion.
- **Generation vs consumption:** most sub-national values describe generation, so importing regions look cleaner than what they consume. Tasmania shows 4 g/kWh; consumption is about 124–200.
- **Climate-based WUE is weak.** It spans only 1.17–1.57 L/kWh. `wue_best_l_kwh` prefers operator-disclosed values (26 countries). `locales.json` does not: its `wue` is the climate estimate, because a disclosure describes one operator's fleet, not a new site; disclosures go in `wue_disclosed`.
- **ISO codes:** India uses the pre-2023 codes (`IN-TG`, `IN-CT`, `IN-OR`, `IN-UT`), which is what Mapbox returns. `AU-WA` is the Perth grid (SWIS) only; `AU-ACT` carries NEM NSW values.
- **Water rates are withdrawal, not consumption.** Grasberg withdraws 7.3 L/kWh but consumes 0.4.
- **Utilisation:** vacancy-based figures overstate energy about 2.6×. Profiles use Ireland's metered ratio instead.
- **Gaps:**
  - Specialty-gas and quartz plant power
  - An inference-only site size
  - Tibet grid factor
  - Mine water per tonne
